# 复现说明

目标：在任意一台 Windows 机器上，用同样的链路重建出体积为 **71 286.571 mm³** 的安装底板，
并得到与提交材料一致的 STL / STEP / FCStd。

## 一、环境清单

| 组件 | 版本 | 说明 |
|---|---|---|
| Windows | 11 24H2 及以上 | 已在 Windows 11 Home China 验证 |
| FreeCAD | 1.1.4 | 需要 `bin\FreeCADCmd.exe` |
| Python | 3.10+ | 建议独立虚拟环境 |
| MCP SDK | 1.30.0（`mcp[cli]<2`） | 2.x 改了 API，会连不上 |
| freecad-mcp | 0.1.32 | 提供 18 个工具 |
| 客户端 | Cherry Studio 2.2.2 | 可选，用于对话式调用 |

## 二、安装

```powershell
# 1. 建虚拟环境（示例放在 D:\mcp-cup\.venv）
python -m venv D:\mcp-cup\.venv

# 2. 安装依赖（注意版本上限）
D:\mcp-cup\.venv\Scripts\python.exe -m pip install "mcp[cli]<2" "freecad-mcp==0.1.32"
```

安装 FreeCAD 后，确认存在：`D:\FreeCAD\bin\FreeCADCmd.exe`。
若路径不同，修改 `freecad_mcp_launcher.py` 中的 `FREECADCMD` 常量。

## 三、注册 MCP 服务器

把 `mcp-config.json` 中的路径改成本机路径，然后：

- Cherry Studio：设置 → MCP 服务器 → 添加 → 从 JSON 导入；
- 或用本目录的 `run_via_mcp.py` 直接以代码方式启动，不依赖客户端。

关键点：**command 必须是 python.exe，args 是 launcher 脚本路径**。
直接把 `freecad-mcp.exe` 配上 `--freecadcmd <路径>` 会在部分客户端里被当成一整串参数，
表现为 `Connection closed`。launcher 把参数在进程内固定，绕开了这个问题。

## 四、重建模型

```powershell
# 方式一：不经 MCP，直接跑 FreeCAD
D:\FreeCAD\bin\FreeCADCmd.exe D:\mcp-cup\project\bracket\build_bracket.py

# 方式二：经 MCP（会额外生成 logs/mcp_call_<时间戳>.jsonl）
D:\mcp-cup\.venv\Scripts\python.exe D:\mcp-cup\tools\run_via_mcp.py
```

两种方式都应该输出：

```
RESULT_JSON {"ok": true, "volume_mm3": 71286.571, ...}
```

## 五、改参数

编辑 `params.json` 后重跑即可，无需改代码：

```json
{
  "length": 120.0,
  "width": 60.0,
  "thickness": 10.0,
  "corner_radius": 3.0,
  "hole_diameter": 4.5,
  "hole_dx": 50.0,
  "hole_dy": 20.0
}
```

也可以在 FreeCAD 里打开 `bracket.FCStd`，直接改 `Params` 工作表中的数字，
然后 `Ctrl+R` 重算。所有特征尺寸都是引用参数表的表达式。

## 六、校验

`build_report.json` 记录了体积、拓扑、包围盒和三个导出文件的 SHA-256。
STL 是二进制格式，同样参数下哈希稳定；STEP/FCStd 头部含保存时间，哈希会变，
但几何指标应完全一致。

预期值：

| 指标 | 值 |
|---|---|
| 体积 | 71 286.571 mm³ |
| 表面积 | 18 371.296 mm² |
| 面 / 边 / 实体 | 14 / 36 / 1 |
| 包围盒 | 120 × 60 × 10 mm |
| STL 三角面 | 876 |

## 七、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `Connection closed` | SDK 2.x，或参数被当整串 | 锁 `mcp[cli]<2`；改用 launcher |
| 看不到工具 | 助手未启用该 MCP | 助手工具页添加 freecad，模式设为自动/手动 |
| 模型让 AI 打开 FreeCAD 界面 | 内置桌面控制在抢活 | 关闭"允许智能体控制桌面应用" |
| 体积对不上 | 参数表被改过 | 恢复 `params.json` 后重建 |
