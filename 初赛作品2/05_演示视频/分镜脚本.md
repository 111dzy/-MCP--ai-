# 演示视频完整录制流程（一镜到底，目标 3 分 40 秒）

> 这份文档按「照着做就行」写。每一节都可以直接执行，不需要再查别的资料。
> 视频文件名：`MCP智造杯_参数化底板_演示.mp4`

---

## 0. 本机实况（先看这一段，和通用教程不一样）

| 项目 | 实际情况 | 对录制的影响 |
| --- | --- | --- |
| 屏幕 | 物理 2560×1600，当前缩放 150% | 直接录会是 2560×1600，不是 1080p |
| 录制工具 | 没有装 OBS；Windows 自带截图工具可用 | 用「截图工具」录，见第 2 节 |
| Game Bar | 已安装 | **不推荐**：录资源管理器/桌面容易黑屏 |
| FreeCAD | `D:\FreeCAD\bin\freecad.exe`（1.1.4） | 双击 FCStd 或从这里打开 |
| MCP 服务器 | Cherry Studio 已配置 `freecad`，指向 `D:\mcp-cup\.venv` + launcher | 打开 Cherry Studio 就能用，18 个工具 |
| 模型输出 | `D:\mcp-cup\out` | 录制前已清空 `bracket.*` |
| 日志 | `D:\mcp-cup\logs` | 已有彩排日志，可直接在视频里展示 |

**关键决定：录制前把显示改成 1920×1080、缩放 100%。** 这样截图工具直接录出标准 1080p，文字大小也正好；录完再改回来。

## 1. 录制前 30 分钟：环境准备

### 1.1 显示器与系统

1. 桌面右键 →「显示设置」：
   - 显示器分辨率：**1920 × 1080**
   - 缩放：**100%**
2. 关闭夜间模式 / HDR（否则录出来偏黄或过曝）。
3. 打开「专注助手 / 勿扰模式」，或 Win+A 关掉通知，避免微信、QQ 弹窗入镜。
4. 任务栏右键 →「任务栏设置」→ 打开「自动隐藏任务栏」（可选，画面更干净）。

### 1.2 软件状态确认（按顺序点一遍）

1. **FreeCAD 能启动**：双击 `D:\FreeCAD\bin\freecad.exe`，出现界面即可，先别打开文件，看完关掉。
2. **Cherry Studio 能连上 MCP**：
   - 打开 Cherry Studio → 设置 → MCP 服务器；
   - `freecad` 显示已连接 / 运行中；
   - 工具列表是 **18 个**，能找到 `execute_code_headless`。
3. **关掉「允许智能体控制桌面应用」**（如果有这个开关），防止录制时 AI 抢鼠标。
4. 确认这两个路径存在：
   - `D:\mcp-cup\project\bracket\params.json`
   - `D:\mcp-cup\project\bracket\build_bracket.py`

### 1.3 桌面整理

1. 关闭微信、QQ、Visual Studio、WPS、浏览器里与比赛无关的标签页。
2. 桌面只留壁纸，图标可以隐藏（右键桌面 → 查看 → 取消「显示桌面图标」）。
3. 录完再恢复，不用担心。

### 1.4 文件现场复位（让画面「从无到有」）

1. 打开资源管理器，地址栏输入 `D:\mcp-cup\out`。
2. 确认里面**没有** `bracket.FCStd`、`bracket.step`、`bracket.stl`、`bracket.2026*.FCBak`、`build_report.json`。
3. 只剩 `_backup`、`param_test`、`param_test.json` 是正常的，不用动。
4. 顺手打开 `D:\mcp-cup\logs` 看一眼，记住最新那个 `mcp_call_*.jsonl` 的文件名（视频里要打开它）。

> 如果录制前又跑了一次构建，`bracket.*` 会重新出现，把上面 5 个文件再删一次即可（删到回收站）。

### 1.5 窗口布局（1080p 下按这个摆）

- **Cherry Studio**：占左侧约 2/3。选中后按 `Win + ←`。
- **资源管理器（`D:\mcp-cup\out`）**：占右侧约 1/3。选中后按 `Win + →`。
- 资源管理器切到「详细信息」视图，按名称排序，方便看到文件出现。
- 把 `params.json` 用记事本或 VS Code 打开，缩到后台，需要展示时再切。

## 2. 录制前 10 分钟：试录

### 2.1 选录制工具

**推荐：Windows 11 截图工具（Snipping Tool）**

1. 按 `Win + Shift + S`；
2. 顶部工具栏点「摄像机」图标（录屏）；
3. 点「全屏」；
4. 打开麦克风开关；
5. 点「开始」。

停止：点顶部工具栏的停止按钮，视频会自动保存到「视频/屏幕录制」文件夹。

**不推荐 Game Bar（Win+G）**：它对资源管理器窗口支持不好，容易录成黑屏。

**可选 OBS**：需要多场景、多音轨时再装。要装我可以帮你下到 `D:\dev\tools`，默认安装包不放 C 盘。

### 2.2 试录 15 秒

录一段：鼠标移动 + 说一句话 + 切换一次窗口。回放检查：

- 文字是否清晰（1080p 下 14px 字体应该很清楚）；
- 麦克风音量是否正常，有没有风扇声；
- 鼠标指针是否太大/太小；
- 有没有通知弹窗。

不满意就调，直到一次过。

## 3. 正式录制：一镜到底分镜

> 全程不暂停、不剪辑。出错就保持录制，继续往下讲，或者整段重录。

### 0:00–0:15　片头

**画面**：Cherry Studio 空白对话页，鼠标不要动。

**口播**：
> 这是成都理工大学 MCP 智造杯的参赛作品。我用 MCP 协议，让 AI 直接驱动 FreeCAD 完成建模。整个过程没有人工建模，也没有打开 CAD 界面。

### 0:15–0:40　展示环境

**动作**：

1. 点 Cherry Studio 设置 → MCP 服务器；
2. 鼠标停在 `freecad` 的「已连接」和工具数量 18 上，停 2 秒；
3. 滚一下工具列表，让 `execute_code_headless` 出现在画面里；
4. 关掉设置，回到对话页。

**口播**：
> 先看环境。客户端是 Cherry Studio，通过 stdio 连接 freecad MCP 服务器，服务器暴露 18 个工具，核心是 execute_code_headless，它能在无界面模式下执行 FreeCAD 的 Python 代码。底层是 FreeCAD 1.1.4 和 freecad-mcp 0.1.32，协议版本 2025-06-18。

### 0:40–1:05　提出需求

**动作**：

1. 切到 `params.json`，停 3 秒，让观众看到 120 / 60 / 10 / R3 / 4.5 这些数字；
2. 切回 Cherry Studio，新建对话，输入下面这段（可提前存到记事本，直接粘贴）：

```
用 freecad MCP 的 execute_code_headless 工具执行下面这段代码，不要使用桌面控制，不要打开 FreeCAD 界面：

PARAMS_PATH = r"D:/mcp-cup/project/bracket/params.json"
exec(open(r"D:/mcp-cup/project/bracket/build_bracket.py", encoding="utf-8").read())
import runpy
runpy.run_path(r"D:/mcp-cup/tools/patch_fcstd_gui.py", run_name="__main__")

执行完后，把输出里 RESULT_JSON 的体积、面数、实体数、三角面数，以及三个文件的字节数和哈希列给我。
```

3. 发送。

**口播**：
> 需求只有一句话：按参数表重建安装底板，导出 STL、STEP 和 FCStd。所有尺寸都在 params.json 里：120 乘 60 乘 10，四角 R3 圆角，四个 M4.5 通孔，孔位正负 50、正负 20。

### 1:05–1:45　观察工具调用（不操作，等待）

**画面**：镜头保留 AI 的推理过程、工具调用卡片、参数和返回结果。鼠标不要乱动。

**口播**：
> 现在 AI 正在调用 MCP 工具。注意，它不是给我一段代码让我自己跑，而是通过 execute_code_headless 在 FreeCAD 里真实执行。建模脚本按参数表生成底板、倒圆角、打孔，再导出三种格式。headless 模式不会保存界面视图信息，所以最后又补了一条 GUI 元数据，保证双击打开就能看到模型。

> 如果这一步超过 60 秒，继续录，不要停。可以补充一句「构建正在 FreeCAD 里执行，我们等它完成」。

### 1:45–2:10　查看结果

**动作**：

1. 切到右侧资源管理器，按 `F5` 刷新；
2. 鼠标依次划过 4 个文件：`bracket.FCStd`、`bracket.step`、`bracket.stl`、`build_report.json`；
3. 双击 `build_report.json`（用记事本打开），鼠标停在 `volume_mm3`、`faces`、`solids`、`triangle_count` 上。

**口播**：
> 执行完成。回到 out 目录刷新，四个文件出现了：FCStd 工程文件、STEP、STL，还有构建报告。报告里体积 71286.571 立方毫米，14 个面，1 个实体，STL 876 个三角面。

### 2:10–2:50　证明模型可编辑（最重要的一段）

**动作**：

1. 在资源管理器里双击 `bracket.FCStd`，等 FreeCAD 打开（约 10–20 秒，不要急着点）；
2. 如果模型偏在角落或被裁切：点顶部菜单 `View → Fit all`（视图 → 适应全部），模型会居中；
3. 左侧模型树：`bracket` → `Params`，下面是 `Bracket`，展开有 `BasePlate`、`CornerFillet_R3`、`M4_Hole_1~4`；鼠标沿树缓慢下滑；
4. 双击 `Params`，表格打开；
5. 找到 `B4` 行（`thickness`，当前值 10），双击数值，改成 **15**，回车；
6. 按 `Ctrl + R` 重新计算；
7. 看底部状态栏/模型属性里的体积，变成 **106929.856 mm³**；鼠标停在这个数字上 2 秒；
8. 如果不放心，切到「模型」标签页看 `Bracket` 的 Shape 体积。

**口播**：
> 再证明它是可编辑的参数化模型，不是一块死网格。用 FreeCAD 打开，左侧是完整的特征树：底板、圆角、四个孔，全部由 Params 参数表驱动。把厚度从 10 改成 15，重新计算——体积变成 106929.856 立方毫米。改一个数字，整块板连同孔位、圆角一起重算，不需要改代码。

### 2:50–3:20　证明可复现与留痕

**动作**：

1. 切到资源管理器，地址栏输入 `D:\mcp-cup\logs`；
2. 双击最新的 `mcp_call_*.jsonl`（用记事本或 VS Code 打开）；
3. 往下滚，指出 `initialize`、`tools/list`、`tools/call` 三种帧；
4. 再打开同名的 `.summary.json`，指出 `protocolVersion`、`serverInfo`、`buildScriptSha256`、`toolCount: 18`。

**口播**：
> 最后是可复现和留痕。每一次 MCP 调用都会记录完整的 JSON-RPC 帧，包括 initialize、tools/list、tools/call；摘要里还有协议版本、脚本哈希和服务器信息。换一台机器，只要参数和脚本在，就能复现同样的几何结果，而且每一步都能核对。

> 说明：视频里展示的日志是同一套脚本、同一套参数预先跑出来的完整记录；画面里的构建是实时重跑的，两者内容一致。

### 3:20–3:40　收尾

**动作**：回到 Cherry Studio 对话页，鼠标静止。

**口播**：
> 自然语言进，可编辑的三维模型出；每一步都有日志和哈希可核对。这就是我们理解的 MCP 智造。

**停 2 秒，再停止录制。**

## 4. 录制中的 8 条纪律

1. 一镜到底，不暂停、不剪辑、不切素材。
2. 每次点击前停 0.5 秒，鼠标移动放慢。
3. 不要快速拖动窗口；窗口切换至少留 1 秒。
4. 等待 AI/FreeCAD 时不要沉默超过 5 秒，用口播解释当前在做什么。
5. 不要展示 C 盘路径、聊天记录、个人文件。
6. 出错不要慌：小错继续讲；大错整段重录，不要剪。
7. 语速控制在每分钟 200 字左右，关键数字读慢一点。
8. 全程不要打开任务管理器、命令行黑框（除非你确定要展示）。

## 6. 故障处置表

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| Cherry Studio 里 freecad 显示未连接 | MCP 进程没起来 | 设置里点重启服务器；仍不行就重启 Cherry Studio |
| AI 不调用工具，直接给代码 | 提示不够明确 | 补一句「必须实际调用 execute_code_headless 执行，不要只给代码」 |
| 工具调用报错 | 参数路径或脚本被占用 | 看返回里的 error；确认 `params.json` 路径正确；重跑一次 |
| out 目录没有新文件 | 构建失败或输出到了别处 | 看 `build_report.json` 是否生成；检查 `output_dir` 是否为 `D:/mcp-cup/out` |
| 双击 FCStd 打开是空白画布 | GUI 元数据没写进去 | 等 10 秒；仍空白就让 AI 再执行一次 `patch_fcstd_gui.py` |
| 模型偏在角落/被裁切 | 相机与窗口尺寸不匹配 | 点 `View → Fit all`，不要手动拖 |
| 改厚度后体积没变 | 改错单元格或没重算 | 确认改的是 `B4`（thickness）；按 `Ctrl + R` |
| 日志目录没有新文件 | 日志由命令行客户端生成，不是 Cherry Studio | 用现有 `mcp_call_*.jsonl`，按 2:50 的口播说明即可 |
| 录出来不是 1920×1080 | 显示设置没改 | 回到 1.1 节，改分辨率与缩放后重启相关软件 |
